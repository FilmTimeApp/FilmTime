## 🔏 صحت‌سنجی

برای مطمئن شدن از سالم بودن فایل، مقدار SHA-256 را با خروجی زیر مقایسه کنید:

**SHA-256 فایل `FilmTime-v1.2.0.apk`:**
```
460d6839432f42ef2dc59ca40a5eb16857189db964d2e8cb626c45c3ebe978d8
```

🧪 نتیجهٔ اسکن آنتی‌ویروس این نسخه روی VirusTotal: **0/68 — کاملاً پاک**

**اثر انگشت گواهی امضای اپ (Signing Certificate SHA-256):**
```
8C:53:07:05:53:D3:44:67:F2:CD:DE:6E:C4:39:D9:79:04:E4:40:28:3B:A8:9C:64:52:7B:13:F9:C3:FB:63:C0
```
> آپدیت‌های رسمی همیشه با **همین گواهی** امضا می‌شوند. اگر هنگام نصب آپدیت جدید پیغام «برنامه نصب نشد / امضا متفاوت است» دیدید، فایل از منبع غیررسمی است — نصب نکنید.

<details>
<summary>🔧 نحوهٔ محاسبهٔ SHA-256 (اختیاری)</summary>

- **اندروید:** با اپ‌هایی مثل «Hash Checker»
- **ویندوز (PowerShell):** `Get-FileHash "FilmTime-v1.2.0.apk" -Algorithm SHA256`
- **لینوکس/مک:** `sha256sum FilmTime-v1.2.0.apk`
